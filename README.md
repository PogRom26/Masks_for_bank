# Учебный проект

### Проект создан для обучения основным функциям и работе с GitHub
### В проекте реализованы следующие функции:
1. Сокрытие части цифр в номере банковской карты или счета ([masks.py](src/masks.py))
2. Определение счета или карты ([widget.py](src/widget.py))
3. Выборка и сортировка списоков ([processing.py](src/processing.py))


## Задания, на взгляд студента, реализованы странно и нелогично. Но кто бы его справшивал ;)


## Установка и использование. 
Склонируйте себе репозиторий и наслаждайтесь!


## Примеры использования. 

Список словарей для примера использования функции выборки и сортировки списков:

[{"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
    {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
    {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},
    {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"},

Выборка списков происходит по ключу. По умолчанию это ключ "EXECUTED", но может быть и выбран "CANCELED".

Пример работы [masks.py](src/masks.py) можно проверить через [main.py](main.py): там указаны примеры номеров карт и счетов.
