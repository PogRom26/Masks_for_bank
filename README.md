# Учебный проект Погорельцева Романа Олеговича

### Проект создан для обучения основным функциям и работе с GitHub и программированию на языке Python
### В проекте реализованы следующие функции:
1. Сокрытие части цифр в номере банковской карты или счета ([masks.py](src/masks.py))
2. Форматирование даты ([masks.py](src/masks.py))
2. Определение счета или карты ([widget.py](src/widget.py))
3. Выборка и сортировка списков ([processing.py](src/processing.py))
4. Фильтрацию списка банковских транзакций по валюте ([generators.py](src/generators.py))
5. Получение списка описаний всех транзакций ([generators.py](src/generators.py))
6. Генерация номера банковской карты в заданном диапазоне ([generators.py](src/generators.py))


## Задания, на взгляд студента, реализованы странно и нелогично. Но кто бы его спрашивал;)


## Установка и использование. 
Склонируйте себе репозиторий и наслаждайтесь!

## Установка зависимостей.
[requirements.txt](requirements.txt) содержит зависимости проекта. 
Для установки можно использовать следующий код: 
```
pip install -r requirements.txt
```

## Примеры использования. 
Примеры использования отражены в тестовых документах в папке [tests](tests).
Результаты тестирования указаны в [index.html](htmlcov/index.html)
На момент проверки автором общий процент равен 98%
2% не проверенных функций - это два списка транзакций в [transactions.py](src/transactions.py), созданном специально для образца.
