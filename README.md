# Учебный проект

### Проект создан для обучения основным функциям и работе с GitHub
### В проекте реализованы следующие функции:
1. Сокрытие части цифр в номере банковской карты или счета ([masks.py](src/masks.py))
2. Определение счета или карты ([widget.py](src/widget.py))
3. Выборка и сортировка списоков ([processing.py](src/processing.py))


## Задания, на взгляд студента, реализованы странно и нелогично. Но кто бы его справшивал ;)


## Установка и использование. 
Склонируйте себе репозиторий и наслаждайтесь!

## Установка зависимостей.
[requirements.txt](requirements.txt) содержит зависимости проекта. 
Для установки можно использовать следующий код: 
```
pip install -r requirements.txt
```

## Примеры использования. 
Примеры использования отражены в тестовых документах в папке [tests](tests).
Результаты тестирования указаны в [.coverage](.coverage)
На момент проверки автором общий процент равен 100% 

## Лицензия.
Проект не лицендируется, так как создан в рамках обучения и не несет особо важной информации, кроме как для студента-создателя.
